# Store interface dependencies

The store uses Motion (motion 14.6.0 and its resolved dependencies) under the MIT license for local UI transitions. Its notice is distributed at `public/licenses/motion.txt` and linked from About. Motion source: https://github.com/motiondivision/motion.

Lucide provides the existing icon set under the ISC license. React, CCC and other dependencies retain their upstream licenses in the installed packages and lockfile. Game-specific art, audio and source credits remain in each game's credits page and repository; see `games/` and About.

The interface loads no animation library from an external CDN. The new WebP covers are format-optimized versions of the existing store artwork; the source PNGs are retained.

The 0.7.0 arcade rules, Canvas renderers, SVG covers and synthesized sounds are original UTXOPlay code under `games/arcade/LICENSE`. No source or assets were copied from the genre references listed in `docs/arcade-release.md`. The Myelin logo was supplied by the site owner.
