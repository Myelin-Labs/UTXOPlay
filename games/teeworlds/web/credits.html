Built on open games.

This is a modified distribution of Teeworlds. Original game by Magnus Auvinen and the Teeworlds contributors. The deterministic fixed-point engine and CKB replayer were ported by xxuejie. Myelin Labs adds the browser renderer, private room service, UTXOPlay account integration, and Myelin session adapter.

What a verified match means

The server runs the original fixed-point simulation at 50 ticks per second and records canonical player inputs. When a round ends, the Myelin adapter independently replays the complete tape in the same pinned native engine and compares the final gameplay snapshot. It binds the tape, participant identifiers, result, and exact engine/map/config artifacts into a signed Myelin session. The exported record can be independently replayed using the repository’s verifier.

This release uses one server authority. It does not provide permissionless consensus, prove fair network ordering, or submit matches to CKB. The upstream CRC is retained for compatibility; cryptographic Myelin commitments bind the tape and result. An interrupted or failed verification is not presented as a verified match.

Match data

Completed match records are linked to your guest or wallet account. Both duel participants can export the shared replay. Guest and wallet accounts remain separate. Live rounds last at most 60 seconds; a server restart interrupts an unfinished round. Finished records persist.
