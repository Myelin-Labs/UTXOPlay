UTXOPlay integration guide

The initial store hosts four curated games and offers a private developer project workspace. This guide distinguishes available interfaces from the planned public publishing platform.

Create a project

Sign in with a supported CKB-compatible wallet, open UTXOPlay Studio, and provide your game name, description, and HTTPS URL. Your draft is private to your account. Registering a URL does not execute its code or publish it.

Available store APIs

EndpointPurpose
GET /api/gamesRead the current public catalog.
GET /api/meRead the current browser account.
GET /api/libraryRead your recently played games.
GET /api/developer/projectsRead your private projects.
POST /api/developer/projectsSave a private project draft.

Authenticated APIs use same-origin, HttpOnly cookies. POST requests require the store Origin. Do not embed privileged tokens or private keys in game bundles.

Local manifest validation

The source repository includes a manifest validation CLI. A minimal manifest looks like this:

{
  "name": "Your game",
  "version": "1.0.0",
  "entrypoint": "https://your.game",
  "genre": "arcade",
  "runtime": "browser"
}

Download the same-origin JavaScript API helper. This helper is for trusted store integrations; it does not provide cross-origin authorization to third-party games.

Myelin runtime integration

Chess and Skyward validate actions in Rust, commit signed Myelin frames, and replay exported evidence. Their game rules and current session implementations are available as references: Chess and Sling. This store release adds account isolation around those runtimes. Teeworlds provides a reference for private multiplayer rooms, canonical input tapes, native replay, and complete-match Myelin frames. Its dedicated room protocol is documented in that repository.

First-person multiplayer reference

Myelin OpenStrike includes a browser FPS client, authenticated 64 Hz room service, native JSONL bridge and standalone Myelin verifier. Read its protocol guide and architecture and trust boundaries. The public game is free; Fiber is a separate optional native testnet experiment.

Next integration stages

General-purpose scoped iframe grants, automated runtime upload, preview deployment, self-service publishing, and a remote multiplayer room SDK are planned capabilities. They are not part of the initial public integration API.
